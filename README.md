# Official Implementation of the ACM Multimedia 2026 Paper

**Non-Uniform Class-Wise Coreset Selection for Vision Model Fine-tuning**

This repository contains the official implementation. The method is available in `train_nat.py` as `--coreset_mode labelwindow_win`.


## Data

The example uses CIFAR-100, which `torchvision` downloads if needed. `--dataset_dir` sets the dataset root (`../data` below).

## Running `labelwindow_win`

Run these three stages from the repository root: train a baseline and record training dynamics, generate per-example scores, then fine-tune with the selected coreset. Adjust paths and GPU settings for your environment.

### 1. Train a baseline and record training dynamics

```bash
python train_nat.py \
  --dataset cifar100 \
  --dataset_dir ../data \
  --model resnet18 \
  --output_dir outputs \
  --name cifar100_baseline \
  --num_epochs 30 \
  --finetune_runs 3 \
  --coreset 0 \
  --td 1 \
  --cuda 1 \
  --gpuid 0
```

### 2. Generate per-example scores

Use the same dataset, model, output directory, and run name as in Step 1.

```bash
python score_nat.py \
  --dataset cifar100 \
  --dataset_dir ../data \
  --model resnet18 \
  --output_dir outputs \
  --name cifar100_baseline \
  --finetune_runs 3 \
  --gpuid 0
```

The score file is written to `outputs/cifar100_baseline/data-score-cifar100_baseline.pickle`.

### 3. Fine-tune using `labelwindow_win`

```bash
python train_nat.py \
  --dataset cifar100 \
  --dataset_dir ../data \
  --model resnet18 \
  --output_dir outputs \
  --name cifar100_labelwindow_win_50 \
  --num_epochs 30 \
  --finetune_runs 3 \
  --coreset 1 \
  --coreset_mode labelwindow_win \
  --coreset_ratio 0.5 \
  --coreset_key el2n \
  --data_score_path outputs/cifar100_baseline/data-score-cifar100_baseline.pickle \
  --cuda 1 \
  --gpuid 0
```

`--coreset_ratio` is the fraction of training examples to retain. `--coreset_key` selects the score used for coreset selection; `el2n` is generated by `score_nat.py`.
